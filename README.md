# 本项目为一套体验DeepSeek-V4.1-Flash编程能力的项目，教程实用性不做保证
在线体验地址：<https://pinelliaazure.github.io/java-learning-lab/>

## Java 学习地图

一套**零依赖的 Java 全栈学习网站**：20 个模块、84 章教材、1197 个小节，从装 JDK 一路讲到 Spring Boot 4、虚拟线程与 AI 工程。全部由静态 HTML / CSS / JS 组成，**双击 `index.html` 就能学**——不需要安装、不需要联网、不需要构建。

面向零基础到中级：每章按「概念 → 语法 → 边界与坑 → 可运行代码 → 运行结果 → 综合案例 → 常见追问 → 自测」组织。代码块一键复制，习题带解析，章节附带静态流程图。

## 怎么打开

直接双击 `index.html`（Chrome / Edge / Safari 均可）。

站点没有任何 CDN、外部字体或第三方脚本，也没有构建步骤；目录里没有绝对路径引用，因此同样可以直接放到任意静态托管（含子路径部署）上访问。

## 三种主题

右上角切换，选择保存在本机：

- **☀ 日间**：暖白纸张底色，适合白天与明亮环境。
- **☾ 夜间**：深色底 + 低亮度代码画布，适合长时间阅读。
- **◐ 跟随系统**：读取 `prefers-color-scheme`，系统切换时页面同步变化。

## 功能

顶栏只放两件事：**搜索**与**学习状态**（已学完 / 84 的进度圆环）。其余功能收在右下角「**☰ 更多**」悬浮菜单里，按用途分三组：

| 分组 | 功能 | 说明 |
|---|---|---|
| 练习与测验 | 模块测验 | 按模块抽 15 题，20 分钟，答对 2/3（≥66%）通过 |
| | 结业考试 | 综合卷，交卷后给评分与逐题解析 |
| | 错题本 | 做错的题集中重做，附解析 |
| | 代码练习 | 输出预测 / 找错 / 填空，31 题 |
| 我的资料 | 书签 | 收藏的课程，一键跳回 |
| | 笔记 | 每课一条笔记，保存在本机 |
| | 进度数据 | 导出 / 导入 JSON，重置学习进度 |
| 拓展内容 | 排序算法实验室 | 跳到 `sorting.html`，12 种排序的逐步动画 |

- **搜索**：点开搜索框或按 `/` 聚焦，可按课程名、模块名、知识点或代码关键词检索；结果按相关度排序、摘要定位到命中位置，`↑` `↓` 选择、`Enter` 直达、`Esc` 收起。同一章最多占 2 条名额，避免单个知识点刷屏。
- **进度**：勾选「我已学完」、测验成绩、上次学到哪一课都写入 localStorage；「进度数据」支持导出 / 导入 JSON，重置只清学习进度，书签与笔记保留。
- **代码块**：统一的 `.cb` 组件——头部三圆点 + 语言标签（Java / 命令 / SQL / XML / 配置 / HTTP / Dockerfile / 文本）+ 常显复制按钮。命令块复制时自动剥掉 `$ ` 提示符，答案块只复制代码不复制「要点」。

## 学习流程

1. **读教材**：目标、路线、分段正文、代码与流程图。
2. **勾选完成**：点「勾选：我已学完本知识点」。
3. **做习题**：每章 3 道题，逐题判分、附解析，答对 2 题（≥2/3）记为已掌握。
4. **进度保存**：勾选、分数与位置全部存在本机。

## 质量校验

仓库自带零依赖校验脚本，改坏内容会直接报错：

| 命令 | 作用 |
|---|---|
| `node tools/verify.js .` | 16 条规则：数据完整性、章尾两节格式、代码块语言标注与内容自洽等；全 PASS 时退出码 0，否则 1 |
| `node tools/audit-sections.js` | 章内结构体检：小节数、占位小节、字数区间 |
| `node tools/audit-tail.js` | 章尾两节格式逐章体检（84 章） |
| `node tools/tag-audit.js` | 代码块语言标注普查，列出非 Java 块与疑似错标 |
| `node tools/run-blocks.js` | 可选闸门：按 `index.html` 顺序加载数据，每个代码块在独立临时目录里 `javac --release 25` 真编译、真运行，并与紧跟的「运行结果」逐行比对；默认退出码 0，`--strict` 才把编译失败与输出差异当失败 |

当前状态：`verify.js` 16 条规则全部 PASS；`audit-tail.js` 84 章 PASS 84 / FAIL 0；84 章在全量无头浏览器回归（1440 / 430 两档视口逐章加载）中无控制台报错、无横向溢出。

### 关于代码块的两个已知前提

- 教材按「逐段演进」的方式给代码：同一个类常在多个块里分步补全，单看某一块可能缺 import 或引用了前文的类。`run-blocks.js` 因此把这类块计为「不可独立编译」，而不是错误。
- 少数示例依赖外部前提（真实 MySQL / Redis、`--add-opens`、输入文件、真实耗时或线程交错顺序），教材在这些块后标明了复现前提；输出数值可能与你机器上的结果不同。

## 技术约定

- **零依赖**：没有 CDN、没有外部字体、没有第三方脚本，没有构建步骤；源码即产物。
- **数据驱动**：目录、精讲、拆解与教材分别是 `JAVA_COURSE` / `JAVA_GUIDES` / `JAVA_DEEP` / `JAVA_TEXTBOOK` 四组全局对象，渲染逻辑集中在 `js/engine.js`。
- **hash 路由**：形如 `#/<章id>`，静态托管不需要任何 rewrite 规则。
- **教材 block 是单键对象**：键名即类型（`h` / `p` / `flow` / `table` / `note` / `code` / `out` / `list` / `ol`）；代码块额外带 `lang`。
- **语言标签固定 8 种**：`java` / `shell` / `sql` / `xml` / `props` / `http` / `docker` / `text`（Gradle、ini、yaml 归 `props`，目录树用 `text`）。内容不做嗅探，一律显式标注。
- **加载顺序由 `index.html` 决定**：数据文件必须先于 `engine.js` 与交互脚本，任何读数据的脚本都要沿用这个顺序。

## 想自己加知识点？

在任意 `curriculum-*.js` 里向对应模块的 `lessons` 数组添加对象；精讲写在 `guides-*.js` 与 `deep-*.js`，教材正文写在 `textbook-*.js`，流程图用 `{ flow: ['步骤 1', '步骤 2'] }` 块。侧边栏、首页统计与模块进度会自动更新。

改完跑一次 `node tools/verify.js .`，16 条规则会把格式问题直接指出来。
